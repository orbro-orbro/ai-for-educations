所有结果必须分清软件验证、合成链路和真实教学观察。设计中的诊断准确率目标 80%、攻击泄漏目标 0 和 10—20 人试点目标都不是当前结果。保持 [protocol](experiments/protocol.md) 与 [results-template](experiments/results-template.md) 的预注册分组、指标、失败/缺失口径，Task 11 不重定义实验。

|类别|当前数据与执行|可支持的结论|
|---|---|---|
|自动化软件测试|真实授权、SQL、HTTP、浏览器、隔离 Runner；最终以对应 HEAD 的 JUnit/命令证据为准|给定测试条件下的软件行为|
|合成数据评测|164 个计划安全案例逐节点映射、54 SQL 向量、15 步彩排、45 次有限 Runner 工作负载；数据均 synthetic/draft|对应固定合成输入的应用与执行链路表现|

|学生试点|尚未执行|无真实自主修复率、复发率、迁移收益或教学效果|

## 执行映射和复算

`evaluate.py` 只验证 schema、来源、唯一 ID 和身份限制，不能产生教学得分。原 security_cases、analytics_vectors、diagnosis_cases 及历史 security_execution_manifest 保持不变。Task 11 使用 `map_delivery_execution.py` 把全部原 164 ID 对到最终完整 backend JUnit 的真实 node、状态、操作、时间和时长，绑定该命令退出码、干净 HEAD、报告 SHA256；数据同时记录 raw 与 LF-normalized hash。小样本案例只接受原 54 SQL Router 参数节点；跨课程 006 核对正确前置条件；日志 008 核对已批准 ADR 0007 的真实断言。

不能把“收集到”“文件全绿”“换一种 fixture 通过”当作计划案例已执行。任何缺失、失败、skip、错用例、错命令、错 HEAD 或 hash 改动均失败。Wave 3 的 163/1 历史状态不被追溯改写；Task 11 另建 manifest，只有其真实通过节点才能记录 automated_passed。

正式 gold 需要许可来源、独立教师双标、裁决前一致性和冻结数据；当前合成批准知识明确 unverified，不是假教师审核。真实模型实验需要精确版本、参数、提示哈希、任务分配、全部失败/超时及缺失记录；学生试点需要招募/同意/撤回与数据治理。未生成正式 observations.json，不运行复算脚本伪造分子分母，结果模板继续未执行。

## 比赛彩排与有限负载

彩排用实际 Web → API → PostgreSQL → controller → 每任务容器；Mock 只替换模型响应。重试正式关联原诊断、真实编译成功与 Mock 理解证据共同产生一次合成自主修复计数。这不是学习者真实修复率。删除前后同一人、课程、purpose 和 query=match 反查，随后只读事务核对两版记忆和来源私人上下文清除。截图只是操作后辅助证据。

Runner 五场景 × 三轮 × 并发 1/2 共 45 次任务，固定每任务 5000 ms、总实验 240 秒、最多两容器。输出成功/失败类型、原始诊断、p50/p95/max、OOM/PID/CPU/内存观测、完整实时创建/销毁事件与残留。原 2000 ms 拓扑回归不放宽。可报告“该限定工作负载通过”，不可外推吞吐容量、长期生产稳定性或历史并发错误已修复。

## 最终证据与限制

统一验证入口执行后生成外置 `evidence-index.json`，包含实际最终 HEAD、各命令记录、通过数量、45 次实验延迟和所有证据文件 SHA256。报告不会把未执行项补零。首次候选失败、编译诊断和浏览器失败保留；最终验证只接受新目录、干净提交，修改后完整重跑，再由独立只读 Agent 复核。

当前检索索引为内存，外部持久向量/缓存/模型引用适配器尚未实现，真实物理擦除未验证；内存索引重启持久化能力不在通过结论内。样本是单课程合成固定输入，Mock 无真实模型随机性，未测试长期/生产高负载，未进行真实教师标注、学生干预或教学因果分析。后续依赖见 [安全报告](security-report.md) 与 [交接](experiments/wave4-task11-handoff.md)。
