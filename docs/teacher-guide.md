# 教师测试指南

欢迎测试「知界·仓颉学伴」。请先看下面两种方式，**选一种即可**。

> 说明：测试用的是**合成数据**，模型响应是**确定性 Mock**，只有仓颉代码编译反馈来自真实的隔离执行器。这不是真实教学试点，也不能作为教学成效证据。请不要把真实学生的姓名、作业或个人信息输入系统。

## 怎么选

| | 方式一：自己的电脑安装 | 方式二：联系我们开机 |
|---|---|---|
| 你需要做什么 | 安装 Docker Desktop，双击启动 | 只需浏览器和邮箱 |
| 适合 | 想随时自己测试、电脑配置较好 | 不想装软件、只测一两次 |
| 是否随时可用 | 是 | 否，需要提前约时间 |
| 首次准备 | 约十几分钟到半小时（取决于网速，**未经干净电脑实测，仅为估计**） | 几分钟 |

## 方式一：在自己的电脑上运行

### 系统要求（估计值，请以 Docker 官方说明为准）

- Windows 10 或 11，64 位。
- 建议内存 8 GB 以上，空闲磁盘 20 GB 以上。
- 电脑需开启虚拟化（多数电脑默认已开启）。
- 首次启动需要联网，会下载并构建镜像。

### 步骤

1. 安装 Docker Desktop：<https://www.docker.com/products/docker-desktop/>，安装后按提示重启电脑。
2. 从开始菜单打开 Docker Desktop，等左下角显示 **Engine running**。
3. 解压我们发给你的教师包，**双击 `start-teacher-local.cmd`**。
4. 等窗口里出现 `[TEACHER_LOCAL_READY]`，浏览器会自动打开 `http://127.0.0.1:5209`。
5. 用教师账号 `demo-teacher` 登录，密码已自动复制到剪贴板，直接粘贴即可。学生账号是 `demo-student-1` 到 `demo-student-6`。

测试结束后，可在 Docker Desktop 里停止 `knowbound-wave4-demo` 项目。

### 常见问题

| 窗口里的提示 | 含义和处理 |
|---|---|
| `DOCKER_MISSING` | 没有安装 Docker Desktop，先安装并重启电脑 |
| `DOCKER_NOT_RUNNING` | Docker Desktop 没有启动，打开它并等 Engine running；仍不行请检查电脑 BIOS 是否开启虚拟化 |
| `DOCKER_NOT_LINUX` | 右键任务栏 Docker 图标，选择 Switch to Linux containers |
| `START_FAILED` | 多半是网络或端口 5209、8208 被占用，请换个网络或关闭占用程序后重试 |
| `WEB_NOT_READY` | 服务刚启动，等一分钟再刷新；仍打不开请联系我们 |

窗口一闪而过时，请打开命令行进入教师包目录，运行 `start-teacher-local.cmd`，再把输出发给我们。

## 方式二：联系我们，由我们开机

1. 联系我们，说明大概想测试的日期和时间段。
2. 我们开机并发给你一个以 `https://` 开头的临时链接。
3. 打开链接，先输入你的邮箱收到的验证码，再用演示账号登录。登录密码我们会通过另一条渠道单独发给你。
4. 这是临时入口：**不保证随时在线**，我们关闭程序后链接就会失效，下次的链接也会不同。

> 当前状态：该方式的代码和说明已准备好，但**还没有开通**，因为需要先确认受邀教师邮箱和访问方案。开通前请先使用方式一，或等我们通知。

## 你的代码草稿

学生端的代码草稿只保存在**当前浏览器**里，不会自动提交，也不会自动给教师。换电脑、换浏览器，或者方式二的链接更换后，旧草稿看不到。公用电脑用完后，请点击“清除本机草稿”。

## 你能看到什么、看不到什么

教师端默认**不能**读取学生的私人对话或完整个人记忆；学生的长期记忆必须经本人确认。这一点在测试里也一样。
