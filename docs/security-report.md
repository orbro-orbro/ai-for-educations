# 安全报告：Task 11 交付边界

本报告覆盖应用权限、合成 PostgreSQL 权威状态和真实隔离执行器。实际通过结论必须绑定最终干净 HEAD 的命令、JUnit 和逐节点映射；候选检查及历史 Wave 3 记录不能替代。新 Critical/Important 安全发现会中止交付结论。

## 权限与数据

仅学生、教师。每次按当前身份、课程关系、所有者、资源状态和目的鉴权；不信任前端角色或资源 ID。教师默认不能读取私人对话、完整记忆或私人诊断；正式作业权限不授予其私人派生数据权限。学生主动分享只覆盖选定诊断摘要、指定教师和目的，撤销后不可读。未知与越权统一 404，内部异常不公开数据库或模型细节。SQL 审计失败时相关敏感操作关闭失败，不能返回成功。

匿名统计按全局及每个筛选/分组的不同学生数检查五人阈值；不足统一样本不足，不公开精确样本数或分母。原始 54 个向量经正式路由和真实 PostgreSQL 重跑，不能用另一种内存算法替换 SQL 权威实现。

长期记忆由本人接受建议后写入；可纠正版本、拒绝建议、删除。删除屏蔽检索，清除记忆各版本正文和相关诊断、提示、解释、建议的私人文本，保留审计、墓碑和必要元数据。正式提交代码与编译反馈属于独立作业记录，本报告不宣称删除操作擦除了全数据库或所有正式作业。删除失败维持 pending 与不可检索状态；有反查及凭证才能完成。logout 将 token 摘要写入权威撤销库，旧令牌不能因进程重建重新有效；回滚移除撤销表前必须更换签名密钥。

## 请求编号与公开契约

[ADR 0007](adr/0007-request-correlation-policy.md) 由用户“这些都是你来决定”委托决策后接受。所有到达应用的请求忽略客户端 X-Request-ID，生成新随机 32 位小写十六进制 ID；响应头与当前错误/审计一致，客户端标记不保留。资源 DTO 的 request_id 仍是创建来源。关联编号不授予权限；HTTP 解析器在应用前的拒绝属于独立传输边界。

原 `sec-sensitive-logging-008` 实际操作保留，增加服务端格式、当前错误/头一致与敏感标记不存在断言。仅 Task 11 的新逐节点证据能关闭这项政策条件；历史清单的 not_executed 保留原样。

[ADR 0008](adr/0008-explicit-retry-association.md) 同样在委托后接受。新增认证 `POST /diagnoses/{diagnosis_id}/attempts`，请求仅 submission_id，204，无新表。服务端复用原有学生所有权、课程/练习一致、不同于原提交及已有执行结果检查，同一对幂等。原完整 OpenAPI 及 Task 6 fragment 同步包含此项。新接口未扩大教师权限，未改变自主修复指标。

## Runner 与运行环境

受信 controller 只传递已验证 JSON；源代码编译和执行均在一次性容器。每任务非 root 10001:10001、network none、只读根、cap_drop ALL、no-new-privileges、512 MiB、1 CPU、64 PID、64 MiB /work tmpfs、stdout/stderr 各最多 65536 字符及固定截止。任务不能选择镜像、挂载、网络或命令。API、Web 和 worker 无 Docker socket；controller 内部有创建沙箱所需的受信 socket，这是主机 Docker 权限边界，必须限制控制面访问。演示 controller 不公开宿主端口；回归 controller 只绑定 loopback 8209。

构建锁定已有 Python 依赖及 wheel SHA256、既有前端 lock、基础镜像摘要和 SDK。依赖锁不等于漏洞扫描或生产供应链审计，本任务未新增此项结论。专用项目/标签/数据库白名单检查在写入前拒绝其他目标。新空卷保留旧合成卷，历史失败日志不删除。
