# ADR 0001：系统边界与共享契约

- 状态：接受
- 日期：2026-10-01

## 决策

系统分为 Web 前端、FastAPI、PostgreSQL/pgvector 和独立仓颉执行器。前端只通过 OpenAPI 调用 API；执行器只接受结构化任务，且不直接访问数据库或模型服务；工作 Agent 通过任务契约片段提出 API 变化，由协调 Agent 串行合并。

## 原因

该边界将学生数据权限、模型生成和不可信代码执行隔离开，减少并行开发时对共享文件的争抢，也让后续安全测试能够针对清晰接口进行。

## 影响

- 执行器不可用时，API 必须明确返回可重试状态，不能伪造编译结果。
- 前端不能依赖数据库结构。
- 共享 OpenAPI、迁移和 Compose 由协调 Agent 维护。
- 后续改变框架、数据库、角色或隔离策略必须新增 ADR。
