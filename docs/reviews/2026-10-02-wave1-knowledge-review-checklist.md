# Wave 1 知识种子教师审核清单

- 种子版本：`2026-10-02.1`；课程：`cangjie-language-design`
- 记录数：概念 48 条、误区 29 条、边 72 条
- 当前状态：全部 `pending_review`，`reviewed_by` 为空。本清单由 Agent 生成，**不构成教师审核**。
- 工具链复现：`python -m app.knowledge.seed verify-snippets` 在 `cjc 1.2.0 (cjnative)` / `cjpm 1.2.0`（Windows x86_64）上检查 27 条带期望结果的误区片段，不一致 0 条。该结果只证明片段行为与记录一致，不证明教学解释正确。
- 数据性质：课程教学与诊断证据种子，不是试点结果，不含学生数据或成效数据。

## 审核方式

1. 由《仓颉语言设计》课程教师逐条判断“摘要/解释是否准确、是否适合作为诊断证据”。
2. 以课程教师账号调用 `POST /teacher/courses/{course_id}/concepts/{concept_id}/review` 或 `.../misconceptions/{id}/review`，请求体只含 `decision`（`approved`/`rejected`/`pending_review`）和可选 `note`。`reviewed_by` 由服务端从已验证的 Bearer 身份写入，请求体不能指定。
3. 任何后续编辑都会把记录重置为 `pending_review`，需要重新审核。
4. 证据闭包规则：误区只有在其本身、根概念、全部关联概念、全部 `explains_error` 来源概念都为 `approved` 时才会成为生产诊断证据。建议先审核概念，再审核误区。
5. 注意：审核接口批准误区时只校验根概念已批准，不校验关联概念；关联概念未批准时误区虽显示 `approved`，仍不会成为证据。
