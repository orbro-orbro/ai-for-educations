# Synthetic competition inputs

Every actor and learning event is synthetic. `match-error.cj` and `match-fixed.cj` are sent to the real isolated Cangjie 1.2.0 Runner. The demo's model responses are deterministic Mock fixtures; their confidence/understanding values are not measured model or teaching performance. Course knowledge approvals are fixture state, not real teacher reviews or gold annotations. No diagnoses, execution results, repair associations, explanation checks or accepted memories are seeded.
